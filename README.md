# مندوب سيارة آب الذكي

منصة عربية (من اليمين لليسار) تتولى العمل اليومي لفريق المبيعات. تبحث عن الشركات المناسبة وتجمع بيانات التواصل المنشورة مع مصدرها، ثم ترسل العرض المعتمد من بريد الشركة. بعد ذلك تتابع حالة التسليم والردود، وتحوّل الفرص المهتمة إلى المندوب المسؤول بمهمة في الموعد الذي طلبه العميل.

> **المعيار:** يحدد المدير مرة واحدة من نستهدف وماذا نعرض، ثم تتولى المنصة العمل اليومي. ويبدأ المندوب يومه وهو يعرف أي عميل يحتاج إلى اتصال، وما العرض الذي وصله، وماذا طلب، ومتى يتابعه.

## الدورة اليومية

| الوقت (الرياض) | ما يحدث على الخادم |

| كل 3 دقائق | يقرأ صندوق الردود ويسجّل حالة الرسالة: «تم التسليم» أو «مرتد» مع سببه. يربط كل رد بالعرض الأصلي ويوقف المتابعة الآلية، ثم يُنشئ مهمة للمندوب في الموعد المطلوب مع تنبيه. وطلب الإيقاف يُسجّل فورًا. |

## الشاشات

- **الرئيسية:** رحلة المبيعات كاملة، من الشركات المكتملة (من أصل الهدف) والسجلات قيد الاستكمال والمكررة، مرورًا بالمؤهلة للتواصل والعروض المرسلة والمسلّمة والردود والمكالمات المُجاب عنها، وصولًا إلى الاجتماعات والصفقات. وتعرض العجز وسببه إن لم يتحقق الهدف.
- **الفئات المستهدفة:** تكتب الطلب بالعربية، فتحوّله المنصة إلى مدن وقطاعات وكلمات بحث عربية وإنجليزية، مع الأنشطة المستبعدة والأولوية والحصة اليومية لكل فئة. منها تعدّل التوزيع، وتختار العرض لكل فئة، وتحدد أيام الإرسال وساعاته وحده اليومي، وتسمح بتعويض النقص من فئة أخرى أو تمنعه، وتعتمد الحملة أو توقفها.
- **الشركات التي أُرسلت إليها عروض** (في القائمة الرئيسية):
  - عدّادان منفصلان: الشركات الفريدة، وإجمالي العروض.
  - تصفية بالفترة والمدينة والقطاع والحملة والمندوب ونوع العرض وحالة التسليم والرد.
  - تصدير النتائج المفلترة إلى Excel.
  - زر «تحتاج متابعة اليوم».
- **سجل الشركة:** بيانات التواصل ومصدر كل منها، وسبب الترشيح ودليله، وكل المصادر المدمجة، والعروض كما أُرسلت فعلًا (النص والمرفق وبصمته). ويعرض الردود والمكالمات والمهام وسجل الموافقات مرتبة بالتاريخ.
- **العروض والمرفقات:** عرض لكل خدمة يتضمن الفوائد المعتمدة والنص والأسعار والخطوة الختامية والملف التعريفي PDF. وأي تعديل يعيد العرض إلى «غير معتمد» حتى يُعتمد مجددًا.
- **ربط بريد الشركة:** Microsoft 365 أو Google Workspace، مع عنوان المرسل واسمه والتوقيع وصندوق الردود، ورسالة تجربة.
- **الفريق والتوزيع:** الأدوار (مدير المنصة، ومدير المبيعات، والمندوب)، وقطاعات كل مندوب ومدنه وحده الأقصى من الفرص، مع أداء الفريق. المندوب يرى شركاته فقط.
- **سجل التشغيل** و**التقرير اليومي** و**الإعدادات والمكالمات** (حالة التكاملات، المساعد الصوتي، استيراد العملاء الحاليين، استيراد دليل أعمال مرخّص، قائمة إيقاف التواصل).
- **صندوق التجربة:** بريد محلي للتجربة قبل الربط الحقيقي. يمكن الرد فيه على أي رسالة كأنك العميل.

لقطات الشاشة في [`docs/screenshots/`](docs/screenshots/).

## الاستهداف حسب طريقة تشغيل المركبات

إلى جانب القطاع والمدينة، يمكن استهداف الشركات بطريقة استخدامها للمركبات، حتى لو كان نشاطها بعيدًا عن النقل. مثال: «ابحث عن شركات لديها فرق ميدانية تزور العملاء يوميًا في المنطقة الشرقية».

| الشريحة | ما تبحث عنه المنصة وتحفظه دليلًا |
|---|---|
| شركات الخدمات الميدانية | فرق صيانة متنقلة، عقود زيارات دورية، خدمة طوارئ |
| شركات التوزيع والتوريد | أسطول التوزيع، توزيع يومي على المتاجر، مستودعات تخدم عدة مدن |
| المقاولون ومشغّلو المواقع | مشاريع موزعة، مركبات خدمة، أسطول معدات |
| الشركات التي تدير توصيلها بنفسها | توصيل وتركيب بفريق الشركة |
| مشغّلو نقل الركاب | عقود تشغيل حافلات ومسارات منتظمة |
| شركاء يخدمون أساطيل متعددة | تتبع المركبات، تأجير الأساطيل، أنظمة إدارة النقل (عرض «شراكة») |

- **عبارة التشغيل:** تُحفظ في سجل الشركة العبارة التي رُشحت بسببها مع رابط صفحتها. شرائح التشغيل لا تقبل شركة دون دليل على تشغيل مركبات؛ متجر تكييف بلا فرق صيانة لا يُضاف.
- **من يشغّل المركبات:** «تشغّل مركباتها بنفسها» أو «تتعاقد مع ناقل» أو «المشغّل غير معروف». إذا ذُكر اسم الناقل يُضاف فرصة مستقلة برابط المصدر، ثم تبحث المنصة عن موقعه الرسمي لاستكمال بياناته. الناقلون الوطنيون الكبار (أرامكس، سمسا، البريد…) يُسجَّلون فقط ولا يُضافون فرصًا.
- **النطاق الجغرافي:** المناطق تتحول إلى مدنها ومحافظاتها، وتُضاف المدن الصناعية والمناطق اللوجستية عند طلبها. ولكل عرض نطاق خدمة (مدن أو مناطق) وشرائح يناسبها، فلا يصل عرض إلى شركة خارج المكان الذي نخدمه.
- **لماذا الآن؟** يرصد الزاحف والبحث الإخباري إعلانات افتتاح مستودع، والتوسع إلى مدينة جديدة، والفوز بعقد تشغيل، وتوظيف سائقين ومشرفي أسطول. تُعرض الإشارة بتاريخها ورابطها، وترفع أولوية الشركة في الإرسال.
- **جهة القرار:** تقترح المنصة الإدارة الأقرب (الأسطول، التشغيل، المشتريات…) وتفضّل بريدها الوظيفي المنشور إن وُجد. وتُربط الفروع بالمقر الرئيسي: الفرع لا يُحتسب شركة جديدة ولا يصله عرض منفصل.
- **«اطلب عرضًا لأسطولك»:** صفحة عامة على `/request-quote` تسأل عن الشركة والمدينة وعدد المركبات والخدمة وطريقة التواصل. كل طلب يُسند للمندوب المختص بمهمة خلال ساعة عمل، ويظهر مصدره (`?src=` للموقع، `?utm_campaign=` للحملة، `?ref=` لإحالة شريك).
- **حصة الاختبار والتقرير الأسبوعي:** أي فئة يمكن وسمها «فئة اختبار» (مثل 80 من 400 لقطاعين جديدين). وفي نهاية كل أسبوع (الخميس) يصل مدير المبيعات تقرير بعدد الاجتماعات لكل 100 شركة تواصلنا معها في كل شريحة، مع الردود المهتمة والصفقات، وتنبيه حين تكون العينة صغيرة.

## قواعد البيانات المهمة (كما طُلبت)

- **تُحتسب الشركة ضمن الهدف** فقط إذا طابقت الفئة وتوفر لها **هاتف وبريد مؤسسي موثّقان برابط الصفحة**. إن توفر أحدهما فقط فهي **«قيد استكمال البيانات»**، وتعود المنصة إلى موقعها لاحقًا للبحث عن البيان الناقص. وتُحتسب يوم اكتمالها.
- **لا تخمين:** يُقبل البريد فقط إن ظهر نصًا في الصفحة، أو في رابط `mailto`، أو في حماية Cloudflare للبريد. ويُرفض البريد المجاني (gmail وما شابهه) والبريد من نطاق غير نطاق الشركة. والأولوية لبريد المشتريات، ثم تطوير الأعمال، ثم المبيعات، ثم البريد العام.
- **منع التكرار** بالاسم الموحّد (عربي وإنجليزي، بعد حذف «شركة» و«المحدودة» و«Co.»…) والنطاق والهاتف والبريد ومعرّف خرائط جوجل. تُدمج مصادر الشركة الواحدة في سجل واحد. وإن عُثر عليها مجددًا تُحدّث ولا تُحتسب جديدة.
- **منع تكرار العرض:** مفتاح فريد لكل (شركة + عرض) في قاعدة البيانات، فلا يتكرر العرض حتى لو ظهرت الشركة في حملتين أو أُعيد تشغيل المهمة. وتُوسم الرسالة «قيد الإرسال» قبل الإرسال حتى لا تُرسل مرتين عند انقطاع مفاجئ.
- **حالات البريد:**
  - «أُرسل»: عند قبول المزوّد للطلب (202 في Microsoft 365).
  - «تم التسليم»: عند وصول تأكيد التسليم فقط.
  - «مرتد»: عند وصول تقرير الارتداد، مع السبب.
- **إيقاف التواصل:** يُسجّل فورًا عند رد العميل بطلب الإيقاف، أو بكلمة «إيقاف» المذكورة أسفل كل رسالة، أو يدويًا. وتُلغى الرسائل والمهام المعلقة وتُستبعد بيانات الشركة من الحملات اللاحقة.

## التشغيل محليًا

```bash
pip install -r requirements.txt
```

```bash
python3 -m pytest -q
```

```bash
ADMIN_EMAIL=admin@sayaraup.test ADMIN_PASSWORD=demo1234 python3 scripts/demo_trial.py
```

```bash
ADMIN_EMAIL=admin@sayaraup.test ADMIN_PASSWORD=demo1234 uvicorn mandoob.web.app:app --port 8000
```

```bash
python3 -m mandoob.worker
```

يعمل عامل الجدولة (`mandoob.worker`) في عملية منفصلة. وللتشغيل في عملية واحدة بدلًا من ذلك اضبط `RUN_SCHEDULER_IN_WEB=1`.

## النشر

ملف [`render.yaml`](render.yaml) جاهز ويُنشئ ثلاثة أجزاء: خادم الواجهة، وعامل الجدولة (ليعمل التشغيل اليومي والمتصفح مغلق)، وقاعدة PostgreSQL دائمة. المرفقات محفوظة في قاعدة البيانات نفسها. التفاصيل وخطوات ربط الحسابات في [`docs/SETUP.md`](docs/SETUP.md).
