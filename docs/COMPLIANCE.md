# ضوابط الامتثال المطبقة في المنصة

> هذه ضوابط تقنية بنيتها المنصة لتسهيل الالتزام، وليست استشارة قانونية. راجعوا مستشارًا قانونيًا بشأن نظام حماية البيانات الشخصية، وأنظمة هيئة الاتصالات والفضاء والتقنية المتعلقة بالرسائل والمكالمات التسويقية، قبل الإطلاق.

| الضابط | كيف تطبقه المنصة |
|---|---|
| بيانات أعمال منشورة فقط | لا تحفظ المنصة إلا هاتفًا أو بريدًا منشورًا علنًا، مع رابط الصفحة التي نُشر فيها. لا تخمين ولا إنشاء عناوين. |
| تفضيل البريد المؤسسي العام | الأولوية لعناوين المشتريات والمبيعات والبريد العام. ويُرفض البريد المجاني والبريد خارج نطاق الشركة وعناوين الموارد البشرية والتوظيف. |
| خرائط جوجل | تُستخدم واجهة Places الرسمية للتعرّف على المنشأة وموقعها الإلكتروني فقط. لا تُخزَّن بيانات الاتصال المأخوذة من خرائط جوجل، وتُستخرج من موقع الشركة نفسه. |
| احترام المواقع | يحترم الزاحف ملف robots.txt، ويعرّف نفسه بـ User-Agent واضح، ويقرأ بضع صفحات فقط لكل موقع. |
| أساس التواصل بالبريد | يُسجَّل لكل شركة أساس التواصل (بريد أعمال منشور، مع الدليل) قبل أول رسالة. |
| هوية المرسل وإيقاف التواصل | تُرسل كل رسالة من بريد الشركة الرسمي باسم «سيارة آب»، ويُذكر أسفلها أن الرد بكلمة «إيقاف» يكفي. ويُسجَّل طلب الإيقاف فورًا لكل القنوات، وتُلغى الرسائل والمهام المعلقة. |
| الارتداد | يُضاف البريد المرتد تلقائيًا إلى قائمة الإيقاف ولا يُعاد استخدامه. |
| المكالمات الآلية | لا اتصال بدون موافقة صريحة مسجلة مع دليلها، وضمن الأحد–الخميس 9ص–5م فقط. يعرّف المساعد بنفسه أنه آلي ويستأذن، ولا يدّعي أنه إنسان، ويسجل طلب عدم الاتصال. |
| الصلاحيات | المندوب يرى شركاته فقط. مدير المبيعات يرى الفريق كاملًا. والإعدادات والربط للمدير. |
| الأسرار | كل المفاتيح في متغيرات البيئة على الخادم. وكلمات المرور مشفرة بـ PBKDF2. |
