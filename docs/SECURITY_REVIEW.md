# تقرير مراجعة أمن منصة «مندوب سيارة آب الذكي»

- **تاريخ المراجعة:** ٢٠٢٦-١١-١٩
- **النسخة المراجَعة:** فرع `security-review`، الإصدار `aba630b`. الإنتاج ما زال على الإصدار السابق `561bdf5`.
- **المرجع:** OWASP ASVS 4.0.3، المستوى الثاني، مع ضوابط أشد للإدارة والأسرار والتصدير.
- **بيئة الاختبار:** معزولة في حاوية المراجعة، على SQLite وعلى PostgreSQL 16، ببيانات اصطناعية فقط:
  - مندوبان، وعميلان يحمل كل منهما علامة سرية FLAG-…
  - ٥٠٠ عميل تجريبي و١٠٠ شركة تدريبية لتمرين الاستعادة.
- **حالة الإنتاج:** لم يُمس. النشر يحتاج اعتماد المالك (قسم ٦).
